# Planning & P6 workflow catalog

| Sequence | Workflow | Primary output |
|---:|---|---|
| 1 | `wbs-development` | WBS dictionary and scope mapping |
| 2 | `activity-list-development` | Complete coded activity register |
| 3 | `calendar-assignment` | Calendar library and assignment matrix |
| 4 | `relationship-assignment` | Logic register and network validation |
| 5 | `baseline-schedule-generation` | Baseline schedule package specification |
| 6 | `resource-loading` | Resource-loaded schedule and histograms |
| 7 | `cost-loading` | Cost-loaded schedule and reconciliation |
| 8 | `cash-flow` | Time-phased cost/revenue/cash-flow model |
| 9 | `procurement-schedule` | Integrated procurement schedule |
| 10 | `material-submittal-schedule` | Material-submittal and approval schedule |
| 11 | `shop-drawing-schedule` | Shop-drawing and design-release schedule |
| 12 | `progress-update` | Controlled update and variance package |
| 13 | `delay-analysis` | Delay event and schedule-impact analysis |
| 14 | `recovery-schedule` | Approved recovery scenario package |
| 15 | `time-impact-analysis` | Fragnet-based TIA package |

Procurement, submittal, shop-drawing, resource, and cost workflows may iterate during baseline development. Any change to an approved schedule reopens affected downstream workflows.
