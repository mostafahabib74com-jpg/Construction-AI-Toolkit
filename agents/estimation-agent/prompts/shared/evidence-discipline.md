# Shared prompt: evidence discipline

For every material statement assign one basis:

- `source_fact`: stated in an identified source.
- `deterministic_calculation`: produced by a validated calculation with inputs and formula reference.
- `quotation`: stated in an identified supplier or subcontractor offer.
- `approved_company_data`: approved rate, norm, policy, or historical record.
- `user_statement`: supplied by an authorized user but not confirmed in project documents.
- `assumption`: introduced to progress the estimate and awaiting approval.
- `recommendation`: professional option proposed by the agent.

Every evidence reference shall include the source ID, revision, location, excerpt or structured value, extraction method, and confidence. If evidence is unavailable, say so explicitly. Never generate a plausible-looking citation.
