# Source and revision control

- Register each original file before analysis and retain its original filename and checksum.
- Record document number, title, discipline, revision, issue date, status, addendum, supersession, location, language, confidentiality, parsing method, and confidence.
- Build an expected-versus-received list from the invitation, indexes, transmittals, portal, and internal records.
- Do not infer completeness from numbering or filenames alone.
- Use only current documents for tender decisions; retain superseded documents for audit and change comparison.
- Compare each addendum against the prior controlled package and identify every affected workflow and artifact.
- A missing, corrupt, password-protected, illegible, conflicting, or unparsed material source is a visible blocker.
