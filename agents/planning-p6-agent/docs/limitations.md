# Limitations

This milestone does not provide a live XER/XML parser or writer, CPM calculation engine, resource leveler, cost/cash-flow engine, schedule-quality engine, delay-analysis engine, P6 database connection, or workbook/report generator.

Prompt outputs remain planning specifications and structured drafts until deterministic tools are implemented and independently validated. The agent cannot approve baselines, certify progress, determine contractual entitlement, or publish to production systems.
