# Delay analysis and Time Impact Analysis

Delay analysis separates factual event chronology, schedule calculation, causation, criticality, concurrency, mitigation, and contractual entitlement. The Planning Agent supplies schedule facts; qualified contract/claims professionals determine entitlement.

## Delay event record

Event ID, description, notice, source evidence, start/finish, knowledge date, responsible party allegation, affected scope, impacted activities, cause/effect narrative, mitigation, status, and schedule versions.

## TIA controls

- Confirm the contemporaneous accepted schedule and data date appropriate to the event.
- Status the schedule to the analysis data date before adding the fragnet.
- Build a discrete, source-based fragnet with realistic durations, calendars, logic, and affected interfaces.
- Preserve a clean pre-impact version and separate impacted scenario.
- Run the validated scheduling engine with documented settings.
- Compare critical/longest path, completion, milestones, float, and path changes.
- Test actual mitigation, concurrency, sensitivity, and subsequent events separately.
- Do not manipulate logic, calendars, or constraints to manufacture entitlement.

The result must state method, limitations, data quality, sensitivity, and required contract review.
