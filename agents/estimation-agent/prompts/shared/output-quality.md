# Shared prompt: output quality

Outputs must be concise enough to review and detailed enough to audit.

## Requirements

- Use controlled document title, number, revision, status, author role, reviewer role, date, and project identifiers.
- Use stable IDs for requirements, scope items, BOQ items, CBS nodes, queries, risks, quotations, assumptions, and actions.
- Use professional construction and commercial terminology.
- Define every abbreviation on first use.
- Present quantities with units and monetary values with currency.
- State whether totals include or exclude tax, escalation, risk, overhead, and profit.
- Show unresolved items prominently rather than burying them in narrative.
- Include an executive decision page and detailed appendices where appropriate.
- Make machine-readable output match the human-readable artifact.
- Do not use decorative claims such as complete, compliant, approved, or ready unless the corresponding validation gate passed.
