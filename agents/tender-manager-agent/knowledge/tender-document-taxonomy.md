# Tender document taxonomy

Register every file before analysis. Typical classes include invitation and instructions; employer/client requirements; scope; specifications; drawings; BIM requirements; BOQ and price schedules; contract conditions; schedules and milestones; forms and declarations; bonds and securities; technical schedules; QA/QC and HSE requirements; sustainability and localization requirements; cybersecurity and data requirements; evaluation criteria; portal instructions; addenda; clarification responses; and reference information.

Capture original filename, logical title, document number, discipline, revision, date, issue status, source location, checksum, supersession, addendum, language, confidentiality, parsing status, and extraction quality. Never infer that sequential document numbers prove completeness.
