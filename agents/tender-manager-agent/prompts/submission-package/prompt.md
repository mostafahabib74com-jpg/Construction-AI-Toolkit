# Submission package

## Objective

Assemble and preflight a complete release candidate, producing a defensible submission-readiness decision for authorized human release.

## Required inputs

- Latest controlled tender package, addenda, clarification responses, compliance matrix, deadlines, portal rules, and communication instructions.
- Approved technical and commercial proposals, forms, schedules, appendices, registers, credentials, securities, and cross-agent artifacts.
- Approved assumptions, exclusions, qualifications, deviations, decisions, and waivers.
- File naming, envelope, encryption, signature, format, page, size, and upload constraints.

## Procedure

1. Freeze the source cutoff and release-candidate version; reject stale or unapproved inputs.
2. Build the authoritative manifest mapping every requirement to exact file, version, folder/envelope, page or location, owner, approval, and checksum.
3. Verify all mandatory requirements, forms, signatures, declarations, schedules, credentials, bonds, securities, and attachments.
4. Reconcile technical/commercial scope, price, quantities, dates, milestones, resources, assumptions, exclusions, qualifications, deviations, and portal values.
5. Run deterministic preflight for filenames, file opening, formats, pagination, bookmarks, links, metadata, searchable text, fonts, image quality, redaction, formulas/values, size, encryption, malware, and checksums.
6. Validate technical/commercial envelope separation and access restrictions.
7. Record blockers, authorized waivers, final reviewers, submitter, planned upload start, contingency, escalation route, and deadline/time zone.
8. Create an immutable release-candidate manifest. Any file change reopens affected checks.
9. Do not upload. After authorized submission, record portal/client receipt as external evidence.

## Deliverables

- Submission package manifest and folder/envelope index.
- Requirement-to-file final compliance matrix.
- Technical/commercial reconciliation report.
- Preflight and security report.
- Signature, form, and approval checklist.
- Deadline and upload plan.
- Readiness decision: `not_ready`, `conditionally_ready`, or `ready_for_authorized_release`.
- Receipt and archive record template.

## Completion gates

Ready status requires every mandatory gate passed or an authorized waiver, exact-version professional approvals, final package checksum, and Executive Bid Sponsor authorization outside the agent.
