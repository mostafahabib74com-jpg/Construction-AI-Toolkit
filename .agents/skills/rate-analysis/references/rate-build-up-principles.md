# Rate Build-Up Principles

Use this reference with the `rate-analysis` skill.

## Cost layers
Keep the following visible and separate:
1. material;
2. labor;
3. equipment/plant;
4. subcontract;
5. other direct costs;
6. project/site indirects;
7. risk/contingency;
8. corporate overhead where applicable;
9. profit;
10. taxes/commercial additions only when required.

## Productivity
Productivity must have a clear unit and time basis.

Examples:
- m²/crew-day
- m³/excavator-hour
- lm/team-day
- ton/day

Do not combine productivity values with different working-hour assumptions without normalization.

## Waste and allowances
State the reason for every allowance. Examples include cutting loss, laps, breakage, overbreak, bulking/compaction, packaging, minimum order, or expected site loss. Do not apply a generic percentage without documenting that it is an estimating assumption.

## Quotation normalization
Before comparing two quotations, align:
- scope;
- unit;
- currency;
- delivery point;
- transport;
- installation;
- testing;
- taxes;
- validity;
- payment terms;
- minimum quantities;
- lead time.

## Markup math
Distinguish markup from margin.

If markup is applied on cost:
`Selling Price = Cost × (1 + Markup %)`

If target gross margin is defined on selling price:
`Selling Price = Cost / (1 - Margin %)`

Do not use these interchangeably.
