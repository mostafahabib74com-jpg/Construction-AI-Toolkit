# Submission control

The submission manifest is the authoritative package index. Record logical deliverable, source artifact, version, filename, format, envelope or folder, mandatory status, page/size limit, encryption, signature, responsible owner, review status, checksum, and final preflight result.

Preflight checks include completeness; latest addenda; filenames; document properties; pagination; bookmarks; links; fonts; image quality; redaction; file opening; searchable text; formulas/values; malware scan; password and encryption handling; signatures; commercial totals; portal fields; envelope separation; file and total size; upload time allowance; receipt evidence; and archive copy.

Submission-ready means every mandatory gate passed or an authorized waiver is recorded. It never means the AI has submitted the bid.
