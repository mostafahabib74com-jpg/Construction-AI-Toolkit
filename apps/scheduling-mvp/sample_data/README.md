# Demonstration data only

Every file in this directory is synthetic demonstration data. It is not derived from a real project, tender, BOQ, quotation, or contract and must not be used as a commercial or construction basis.

The application does not automatically load these values into user-created projects.

- `sample_project.json` and `sample_boq.csv` exercise Milestone 1 intake.
- `milestone_2_demo_schedule.json` exercises WBS, a working calendar with a break and exception, explicit activity inputs, relationships, duration calculation, and forward planned dates.
