# Limitations

The Estimation Agent specification does not currently provide:

- Live PDF, drawing, spreadsheet, BIM, or P6 parsing.
- Automated quantity takeoff.
- Deterministic calculation services.
- Live regional cost or productivity data.
- Live exchange, commodity, inflation, tax, duty, logistics, or supplier data.
- An executable Excel workbook generator.
- Contract, tax, legal, insurance, or accounting advice.
- Authority to approve, sign, commit, or submit a bid.

Until those services are implemented and validated, prompt outputs are structured drafts and calculation specifications. Users must not interpret them as completed professional estimates solely because the format appears authoritative.
