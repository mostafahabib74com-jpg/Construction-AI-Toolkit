# Shared prompt: P6 file integrity

Never claim a valid P6 schedule from a table alone. XER/XML import and export require schema/format validation, stable-ID preservation, field-coverage reporting, scheduling-option capture, unknown-field preservation where supported, clean-environment import test, recalculation comparison, record-count comparison, date/float/cost comparison, warning review, and checksum/version manifest. Production database writes require separate authorization.
