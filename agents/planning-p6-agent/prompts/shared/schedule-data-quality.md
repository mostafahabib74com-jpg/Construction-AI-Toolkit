# Shared prompt: schedule data quality

Check identifiers, WBS mapping, dates, durations, calendars, logic, constraints, codes, percent-complete type, resources, costs, actuals, remaining values, milestones, and settings. Detect duplicates, blanks, loops, open ends, leads, excessive lags, unsupported constraints, invalid dates, future actuals, remaining work before data date, inconsistent progress, unusual float, missing codes, and broken reconciliation. Use configured thresholds and explain exclusions.
