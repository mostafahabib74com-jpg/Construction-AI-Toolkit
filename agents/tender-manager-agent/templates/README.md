# Tender template library

The library defines blank, controlled structures for tender coordination. It contains no project data and no approved defaults.

## Contents

- `folder-structure/`: controlled source, working, review, release-candidate, receipt, and archive layout.
- `registers/`: canonical UTF-8 CSV headers for document, requirement, query, contribution, proposal, resource, commercial, and submission controls.
- `proposals/`: required technical, commercial, and execution-methodology outlines.
- `submission-package/`: manifest, preflight, release, receipt, and archive specification.

## Rules

- Preserve stable IDs and exact tender/source/artifact versions.
- Use ISO 8601 dates and explicit time zones.
- Do not put formulas in CSV exchange files.
- Keep confidential commercial and personal information in access-controlled locations.
- Do not treat a completed template as approved, compliant, calculated, rendered, signed, or submitted.
