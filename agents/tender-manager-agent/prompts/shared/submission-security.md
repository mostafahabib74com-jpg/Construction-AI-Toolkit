# Submission security and release control

- Treat package assembly and portal upload as separate steps.
- Validate approved versions, filenames, formats, page and file-size limits, envelope separation, forms, signatures, encryption, passwords, redaction, links, metadata, malware scan, and checksums.
- Open and inspect every generated file using the final delivery application or a validated preflight tool.
- Maintain a manifest and immutable release candidate; do not replace files after approval without reopening checks.
- Record submission deadline, time zone, planned upload start, contingency, authorized submitter, portal status, and escalation path.
- Never reveal credentials, bypass security, sign on behalf of a person, upload without authorization, or claim receipt without portal/client evidence.
