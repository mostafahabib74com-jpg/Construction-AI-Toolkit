# Tender Manager Agent workflow catalog

| Sequence | Workflow | Primary output | Required for submission |
|---:|---|---|---|
| 1 | `tender-package-ingestion` | Controlled document and deadline register | Yes |
| 2 | `tender-folder-organization` | Folder plan and filing manifest | Yes |
| 3 | `compliance-matrix` | Requirement and response matrix | Yes |
| 4 | `clarification-management` | Clarification register and response-impact log | When applicable |
| 5 | `rfi-generation` | Controlled tender RFI package | When required |
| 6 | `assumptions-register` | Approved tender assumptions register | Yes |
| 7 | `exclusions-register` | Approved tender exclusions register | Yes |
| 8 | `execution-methodology` | Project execution methodology | Yes |
| 9 | `organization-chart` | Organization chart and responsibility schedule | Yes |
| 10 | `project-schedule` | Tender schedule package | Yes |
| 11 | `equipment-schedule` | Equipment schedule and availability basis | When required |
| 12 | `manpower-histogram` | Manpower data and chart specification | When required |
| 13 | `technical-proposal` | Coordinated technical proposal | Yes |
| 14 | `commercial-proposal` | Reconciled commercial proposal | Yes |
| 15 | `submission-package` | Manifest, checklist, readiness decision, and package | Yes |

Workflows may iterate. An addendum, clarification response, pricing change, schedule revision, or contributor change reopens every affected downstream artifact. Submission readiness requires the approved version of each applicable upstream output.
