# Proposal quality

- Follow the required response structure, evaluation criteria, terminology, language, page limits, and form instructions.
- Lead with a direct compliant answer, then method, controls, evidence, benefit, and cross-reference.
- Use verified, tender-relevant evidence. Remove generic filler, repetition, unsupported superlatives, vague commitments, and competitor comparisons.
- Align executive summary, methodology, organization, resources, schedule, procurement, BIM, quality, safety, sustainability, risks, and commercial basis.
- Use consistent names, abbreviations, units, dates, numbers, captions, and cross-references.
- Mark graphics and tables with source data, version, owner, and accessibility text.
- Never sacrifice compliance clarity for persuasive language.
