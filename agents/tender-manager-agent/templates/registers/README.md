# Register templates

These files contain canonical UTF-8 CSV headers for controlled exchange. They are blank schemas, not project data.

- Keep exactly one header row in canonical copies.
- Use stable IDs, ISO 8601 dates, explicit time zones, and exact source/artifact versions.
- Do not place formulas, merged cells, hidden rows, macros, passwords, signatures, or binary attachments in CSV.
- Use deterministic services for counts, totals, schedules, headcount conversion, charts, and reconciliations.
- Keep confidential commercial and personal registers access-controlled.
- Use semicolon-separated identifiers only where plural columns explicitly permit them; structured JSON remains preferred for machine orchestration.
