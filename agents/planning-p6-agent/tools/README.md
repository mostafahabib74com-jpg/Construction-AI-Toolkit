# Planning & P6 Agent tools

No runtime tools are implemented in this milestone.

Required future tool families:

- XER and P6 XML parser/writer with round-trip validation.
- Schedule data validator and stable-ID mapper.
- Deterministic CPM and longest-path engine.
- Calendar, duration, and lag normalization.
- Schedule-quality and configurable DCMA assessment.
- Resource loading, histogram, and leveling engine.
- Cost loading, time phasing, and cash-flow engine.
- Baseline/update variance engine.
- Delay-event, fragnet, and TIA scenario engine.
- Workbook, report, and dashboard generator.

Every execution records tool version, settings, input schedule hash, output schedule hash, warnings, calculations, and validation status.
