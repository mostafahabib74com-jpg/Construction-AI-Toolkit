# Output quality

- Use the exact workflow schema and template fields.
- Keep IDs stable and make tables import-friendly.
- State status, version, source cutoff, latest addendum, owners, due dates, reviewers, approvals, and unresolved blockers.
- Use concise professional language suitable for a senior tender review.
- Surface mandatory noncompliance and deadline risk before narrative detail.
- Provide both machine-readable records and a human-readable summary when requested.
- Do not claim an artifact was rendered, calculated, checked, signed, packaged, uploaded, or received unless the required tool evidence exists.
