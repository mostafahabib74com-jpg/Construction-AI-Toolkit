# Requirement traceability

- Decompose combined clauses into atomic requirements without losing the original source context.
- Assign stable IDs, category, mandatory/scored status, evaluation weight where known, owner, contributor, due date, response location, evidence, compliance state, and review status.
- Map duplicate requirements and preserve each source occurrence.
- A mandatory requirement cannot be marked compliant without an approved response and evidence.
- A planned response, draft form, unverified CV, proposed schedule, or unresolved query is not compliance evidence.
- Propagate addendum changes and client answers to all dependent requirements and deliverables.
- Report missing owners, overdue inputs, conflicts, gaps, deviations, and unverified evidence.
