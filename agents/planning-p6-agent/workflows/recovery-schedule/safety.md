# Recovery Schedule safety and review rules

## Required controls

- Apply the Planning & Primavera P6 Agent system prompt and every declared shared prompt.
- Use controlled sources, an explicit schedule version, and a recorded data date.
- Preserve source schedules; create a new version for every draft, update, scenario, recovery, or impact model.
- Do not invent dates, durations, logic, calendars, resources, costs, actuals, constraints, or progress.
- Use validated deterministic tools for CPM, calendar, resource, cost, cash-flow, and delay calculations.
- Treat schedule facts, planning judgment, scenarios, and contractual entitlement as separate categories.
- Do not approve, certify, overwrite, publish to production P6, or determine entitlement.

## Workflow-specific blockers

- `undefined_recovery_target`
- `infeasible_recovery_logic`
- `missing_resource_limits`
- `unvalidated_recovery_model`

## Mandatory reviewers

- Planning Manager
- Project Controls Manager
- Construction Manager
- Project Director

A blocked condition may be cleared only by new controlled evidence or an authorized, recorded decision.
