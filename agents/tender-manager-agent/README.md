# Tender Manager Agent

The Tender Manager Agent is the controlled tender-orchestration and proposal-assembly module of the Construction-AI-Toolkit AI Engineering Platform.

## Mission

Read and control complete tender packages, coordinate compliance and tender queries, assemble approved technical and commercial content, and produce a traceable submission-ready package for authorized human approval.

## Supported capabilities

1. Tender-package ingestion and revision control.
2. Tender-folder organization.
3. Compliance-matrix generation.
4. Clarification-register generation.
5. RFI generation.
6. Exclusion-register generation.
7. Assumption-register generation.
8. Technical-proposal assembly.
9. Commercial-proposal assembly.
10. Execution-methodology development.
11. Organization-chart specification.
12. Equipment-schedule development.
13. Manpower-histogram specification.
14. Tender project-schedule coordination.
15. Submission-package assembly and readiness review.

## Core principles

- Every requirement, response, qualification, form, and deliverable is linked to a controlled source and revision.
- Addenda and client clarifications reopen affected analyses and invalidate superseded conclusions.
- Approved domain-agent outputs are consumed as immutable artifacts; the Tender Manager Agent does not rewrite validated estimates, schedules, quantities, designs, quality controls, or safety controls.
- Commercial totals, schedule calculations, manpower histograms, and document checks use validated deterministic services.
- Company credentials, personnel, equipment, experience, and certifications must be current, approved, and permitted for the tender.
- The agent does not approve bid/no-bid, commit price, sign forms, issue correspondence, authorize submission, or upload to a client portal.

## Maturity

This milestone provides the prompt, workflow, schema, template, evaluation, review, and integration specification. It contains no executable document parser, proposal renderer, scheduling engine, chart generator, or tender-portal connector.

See `docs/workflow-catalog.md` for the controlled sequence and `templates/README.md` for the submission template library.
