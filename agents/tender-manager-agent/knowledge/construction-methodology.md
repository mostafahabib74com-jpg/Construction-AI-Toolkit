# Construction execution methodology

A tender methodology must align scope, site conditions, design maturity, temporary works, logistics, sequence, work packaging, resources, procurement, interfaces, permits, quality, safety, environment, testing, commissioning, handover, and the tender schedule.

For each work package state inputs, prerequisites, responsible parties, plant, labor, materials, sequence, controls, inspections/tests, hold points, HSE controls, environmental controls, outputs, interfaces, risks, contingencies, and schedule links. Treat construction-manager, engineering, QA/QC, HSE, BIM, procurement, and planning reviews as mandatory where applicable.

Do not invent methods or declare feasibility when the source design, access, temporary works, permits, production basis, or specialist input is missing.
